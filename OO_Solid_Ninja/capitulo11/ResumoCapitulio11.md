# Capitulo 11 - Conclusão

Fazer um projeto de classes orientado a objetos é uma tarefa complexa, e muitas vezes, mesmo com as melhores intenções, acabamos criando um código que não é tão limpo ou organizado quanto gostaríamos. No entanto, aplicar algumas práticas e princípios SOLID  podem nos ajudar a criar um código mais limpo e organizado.
